# Game Design Skill v0.1.0

First release. One router skill that helps game designers analyze and develop designs: it reads the material, gathers missing context with at most three questions, picks the relevant design lenses and returns a prioritized report with minimal fixes and next steps.

## Included

- Router skill with intake, lens selection, analysis rules, P1-P3 severity, Observed/Inferred/Assumed confidence labels and a fixed report template.
- Nine lens families loaded on demand: emotional direction, player motivation, core loop and pillars, flow/fairness/failure, FTUE and retention, multiplayer and social, prototyping, pitch and GDD, scoping and budget.
- Claude Code plugin and marketplace manifests; optional Codex interface metadata; direct skill routes for other filesystem agents.
- Recorded trials: a core loop audit and an intake check run by a Claude subagent, and an FTUE review run in Codex, each with its limits.
- Standard-library package tests and a four-job CI matrix.
- MIT license bundled with the standalone skill.

## Limits

The skill structures design reasoning and does not replace playtesting. Codex discovery and use were observed. In Claude Code the plugin validates and loads from disk, but a model session with it was not yet observed. Other hosts rely on documented routes. See docs/validation.md.
