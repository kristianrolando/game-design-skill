# Game Design Skill v0.1.1

A small fix to the report format, found by trials, plus the evidence and README work since v0.1.0.

## Changed

- **Deliverable section is now strictly for artifact requests.** In a v0.1.0 trial, a diagnosis request ("is the emotional direction clear?") produced a `Deliverable` section with a proposed tone guide. SKILL.md now states that Deliverable appears only when the user asked for an artifact, and that diagnose and decide requests describe any proposed artifact inside the minimal fix that needs it. The Summary must also answer each question the user asked. Regression runs are recorded in docs/validation.md.

## Added since v0.1.0

- Redesigned README with responsive banner artwork, an intake flow diagram and a verbatim report excerpt.
- Trials covering all nine lens families, including Claude Code plugin and direct-skill sessions and a Codex session.
- Evidence for the public install routes (Skills CLI and the GitHub marketplace).

## Unchanged

The nine lens files, the workflow, ratings and every other report section. Reports keep the same headings.

## Limits

Trials are single runs per case with invented concepts; they show the skill is followed as written, not that its advice is right for a real game. In Codex, develop requests return only the requested document, without the surrounding report; this predates v0.1.1. See docs/validation.md.
