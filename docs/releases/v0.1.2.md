# Game Design Skill v0.1.2

A small fix to the report format for develop requests, found by the v0.1.1 regression runs.

## Changed

- **Develop requests keep the full report.** When asked for an artifact such as a one-page design doc, Codex returned only the document, without the Summary, findings, priority table, minimal fixes and next steps. SKILL.md now states that every output follows the report structure, develop requests included, that asking for an artifact is not a request to switch formats, and that the artifact goes under Deliverable with every other section kept around it, each brief. In regression runs, all three Codex develop runs kept the full report (previously none of three did), and diagnose reports still left Deliverable out. Evidence: docs/evidence/regression-v0.1.2-2026-11-03.md.

## Unchanged

The nine lens files, the workflow, ratings, the v0.1.1 Deliverable rule for diagnose and decide requests, and the report headings.

## Limits

Trials are few runs per case with invented concepts, on one model per host, and covered one artifact type (a one-page design doc). Codex still drifts in minor formatting, such as an omitted Lens column. See docs/validation.md.
