# Security policy

This package is text: Markdown instructions, YAML and JSON manifests, and a test suite. It runs no code of its own in a host agent and stores no data. Security problems are still possible, for example wording that makes an agent follow instructions embedded in reviewed material, write files without being asked, or leak supplied design documents.

## Supported versions

Only the latest release receives fixes. Published tags are never moved; fixes ship as a new release.

## Reporting

Report privately through [GitHub's vulnerability reporting](https://github.com/kristianrolando/game-design-skill/security/advisories/new). Do not open a public issue. Include the host and version, the skill version, the prompt and a minimal input that shows the behavior.

Expect an acknowledgement within seven days. Confirmed problems are fixed in a new release and credited in its notes unless you prefer otherwise.
